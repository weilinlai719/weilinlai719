# .github/workflows/update-readme.yml
name: Update README

on:
  schedule:
    - cron: '0 0 * * *'  # 每天執行
  workflow_dispatch:

jobs:
  update:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      
      - name: Update README
        run: |
          # 你的更新腳本
          node update-readme.js
      
      - name: Commit changes
        run: |
          git config --local user.email "action@github.com"
          git config --local user.name "GitHub Action"
          git add README.md
          git diff --quiet && git diff --staged --quiet || git commit -m "docs: auto update README"
          git push

七、常見錯誤
❌ 避免的錯誤：

1. 太長太複雜
   - README 應該簡潔有力
   - 不是越多越好

2. 過時的資訊
   - 定期更新內容
   - 確保連結有效

3. 太多 GIF 和動畫
   - 會影響載入速度
   - 可能分散注意力

4. 誇大不實
   - 不要列出不會的技術
   - 誠實展示實力

5. 忘記更新
   - 加入新技能要更新
   - 專案狀態要更新
